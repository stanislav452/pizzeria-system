# Лабораторна робота №1: Консольний застосунок на Java
 
Предметна область: Електронне меню піцерії.



 Опис сутностей

* Піца: назва (`String`), ціна за одиницю (`double`), діаметр у см (`int`).
* Замовлення: кількість штук (`int`), наявність додаткового соусу (`boolean`).



 Обчислювальна операція

1. Додатковий соус: якщо `includesSauce == true`, додається +25.0 грн за кожну піцу.
2. Система знижок:
   - 15% - при замовленні від 3 піц або загальній сумі від 600 грн.
   - 5% - при замовленні 2 піц.



 Інструкція запуску

1. Компіляція:
   javac Main.java
   java Main
