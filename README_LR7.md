# ЛР №7–9: типізований CRUD-сервіс

Цей розділ доповнює проєкт піцерії з попередніх лабораторних. Існуючий `Main.java` не змінювався: основна консольна програма ЛР1–6 збережена. Для показу CRUD додано окремий запускний клас `CrudDemo`.

## Додані класи

- `BaseEntity` — спільні незмінні `id` та `name`; `equals()` і `hashCode()` визначають сутність за `id`.
- `Pizza` і `Order` — типізовані сутності предметної області.
- `EntityNotFoundException` — неперевірений виняток (`RuntimeException`) з id сутності, яку не знайдено.
- `CRUDService<T extends BaseEntity>` — спільний CRUD-контракт. Обмеження generics дає сервісу гарантію, що будь-яка сутність має `id` і `name`.
- `InMemoryCrudService<T>` — реалізація на `LinkedHashMap<Long, T>`: пошук, додавання/оновлення та видалення за id.
- `PizzaService` / `OrderService` — конкретні контракти сортування; їх методи не входять у загальний сервіс, бо ці сутності мають різні поля.
- `InMemoryPizzaService` / `InMemoryOrderService` — сортують через `Comparator`.
- `CrudDemo` — показує сценарії лабораторної, не замінюючи основний `Main`.

## Пояснення вибору

`LinkedHashMap` дає в середньому O(1) для пошуку, збереження та видалення за id і зберігає порядок вставки. `ArrayList` має O(n) пошук і видалення за id; `HashMap` має середнє O(1), але не зберігає порядок; `TreeMap` має O(log n) пошук/запис/видалення. Сортування списку-копії займає O(n log n).

Використаний `Comparator`, оскільки правила відрізняються: піци сортуються за назвою й ціною, замовлення — за назвою й кількістю. `findAllSorted` приймає `Comparator<? super T>`, щоб підійшов компаратор як для T, так і для його батьківського типу. Сортування не змінює сховище.

`List<Pizza>` не є підтипом `List<BaseEntity>`. Для друку використано `Collection<? extends BaseEntity>`, що дозволяє передавати колекцію будь-якого типу-нащадка.

Порядок компаратора не обов'язково узгоджений з `equals`: `equals` порівнює id, а сортування — назву та поле сутності. Для впорядкованого списку це нормально; такий компаратор не слід використовувати як критерій унікальності в `TreeSet`.

## Запуск

Потрібен JDK. У корені проєкту:

```bash
javac *.java
java CrudDemo
```

Щоб запустити попередню інтерактивну програму, виконайте `java Main`.

## Що демонструє запуск CRUD

Додаються три піци, дві з однаковою назвою; показуються список і сортування за назвою та ціною. Потім запис з id=1 оновлюється без збільшення кількості записів, видаляється наявний запис, а спроби пошуку та видалення відсутнього id обробляються винятком. Наприкінці демонструється сортування замовлень за назвою та кількістю.
