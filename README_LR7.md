# ЛР №7–9 у спільному проєкті піцерії

Це продовження лабораторних №1–6, а не окремий застосунок. Усі попередні класи та консольний сценарій збережені. `Main.java` лишається точкою запуску інтерактивного сценарію: після основної демонстрації він показує CRUD для замовлень піци. Починаючи з ЛР №10 проєкт збирається Maven, а класи лежать у пакеті `ua.edu.pizzeria`.

## Інтеграція

`PizzaOrder` тепер успадковує `BaseEntity`: назва замовлення піци доступна як `name`, а кожен об'єкт має незмінний `id`. Для звичайного введення id створюється автоматично; для демонстрації оновлення є конструктор, що дозволяє задати id. `PickupOrder`, `DeliveryOrder` та `ExpressDeliveryOrder` залишаються частинами тієї самої ієрархії.

`CRUDService<T extends BaseEntity>` задає пошук, отримання списку, збереження, видалення та сортування. `InMemoryCrudService` зберігає об'єкти в `LinkedHashMap<Long,T>`. `PizzaOrderService` додає сортування за назвою піци й ціною. Сортування повертає копію списку.

`BaseEntity.equals()` та `hashCode()` використовують id; тому ці методи тепер однаково працюють для всієї ієрархії замовлень. Пошук старого інтерактивного прикладу окремо порівнює поля замовлення.

## Демонстрація

Наприкінці роботи `Main` показує три замовлення, два з однаковою назвою, сортування за назвою та ціною, оновлення без збільшення кількості записів, успішне видалення та обробку відсутнього id.

## Запуск

Потрібен JDK 21 або новіший. У корені проєкту:

```bash
mvn compile
mvn exec:java -Dexec.mainClass=ua.edu.pizzeria.Main
```

Спершу введіть дані, які просить основна програма. CRUD-демонстрація запускається автоматично після завершення пошуку замовлення.
